# Mo5tareb (مغترب)

Run it:
    npm install
    npm run dev
Then open the address it prints (usually http://localhost:5173).

Structure
    src/i18n/translations.js   all Arabic + English text
    src/context/AppContext.jsx language, current page, go("page")
    src/pages/                 one file per page (landing/ holds home sections)
    src/components/            reusable pieces (Button, Input, Navbar, ...)
    public/images/             your photos (see README.txt inside)
